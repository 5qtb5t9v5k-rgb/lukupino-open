# Infograafi

Lukupinon yhden kuvan esittely: mikä se on, miten se toimii ja mitä se mahdollistaa.

| Tiedosto | Mitä |
|---|---|
| `infograafi.html` | Lähde (alun perin Design-kanvas 20.10.2026) |
| `piirra.mjs` | Piirtää `docs/kuvat/infograafi.jpg`:n Playwrightilla |
| `../../docs/kuvat/infograafi/` | Infograafin puhelinkuvakaappaukset |

```bash
node scripts/infograafi/piirra.mjs
```

Muokkaa tekstiä `infograafi.html`:ssä ja piirrä uudelleen. Leveys on 1080 px;
korkeus määräytyy sisällöstä.
